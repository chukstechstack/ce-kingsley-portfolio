## 🚀 Features

* **Editorial UI/UX Layout:** Clean, minimalist design with custom typography and micro-interactions.
* **Interactive Modals:** Dynamic About and Contact dialogue drawers.
* **Direct CV Download:** Integrated secure asset downloading for recruiters.
* **Fully Responsive:** Optimized fluid scaling from mobile screens to massive ultrawide displays.

## 📦 Getting Started Locally

Clone the repository and run it locally on your machine:

```bash
# Clone the repo
git clone [https://github.com/chukstechstack/ce-kingsley-portfolio.git](https://github.com/chukstechstack/ce-kingsley-portfolio.git)

# Navigate into the directory
cd portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
